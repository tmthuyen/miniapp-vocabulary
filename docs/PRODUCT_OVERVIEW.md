# Product Vision - IELTS/TOPIC English Learning Web

## Scope in this phase
- Authentication with Supabase Auth.
- Authorization with role-based access: admin and user.
- User subscription model: free, vip_basic, vip_pro with expiry date.
- Vocabulary CRUD and CSV import (admin only for write actions).
- Vocabulary learning games for user practice.

## Roadmap after this phase
- Listening dictation.
- Speaking recording and AI scoring.
- TOEIC/IELTS contest mode.
